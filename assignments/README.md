## 单次作业目录模板

```
hw01-data-cleaning/
├── README.md        # 题目要求、解题思路、实验结果与结论
├── main.py          # 主程序入口（或 .ipynb）
├── requirements.txt # 该作业额外依赖（可选）
└── output/          # 运行结果、图表（小文件可入库）
```

## 作业 README 建议结构

1. **题目要求** —— 用自己的话复述，确认理解无误
2. **数据说明** —— 数据来源、规模、字段含义
3. **解题思路** —— 方法选型与理由
4. **实验结果** —— 关键指标、图表
5. **结论与反思** —— 做对了什么、哪里可以改进
