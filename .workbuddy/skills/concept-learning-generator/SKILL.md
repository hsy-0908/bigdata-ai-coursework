# 概念学习资料生成Skill
## 适用场景
对任意人工智能、大模型相关概念生成完整学习资料，不限于Agent、上下文等指定主题，支持任意新概念输入。

## 输入
参数：`concept_name`，字符串类型，接收要讲解的技术概念名称。

## 执行步骤
1. 获取传入的 concept_name 概念名称
2. 生成该概念对应的学习目标，明确学完后需要掌握的能力
3. 提出理解该概念的核心思考问题
4. 撰写个人理解：个人对该概念通俗解释
5. 梳理核心原理与组成结构
6. 列举现实业务落地应用场景
7. 区分易混淆概念，说明使用局限与边界
8. 生成自测问题，用于检验对概念掌握程度
9. 搜集真实可访问的公开参考资料链接，禁止编造链接
10. 输出完整HTML格式文件

## HTML输出强制5大章节
1. 学习目标：学习该概念后应当掌握的能力要点
2. 核心问题：理解本概念需要回答的关键思考题
3. 个人对概念的理解
4. 核心机制与组成
5. 实际应用场景
6. 易混淆概念与使用边界
7. 自测问题：检验是否掌握概念的思考题
8. 可核查参考资料

文件命名规则：概念转小写，横杠分隔，如 Agent → agent.html

## 资料规范
参考链接必须是互联网真实公开地址，禁止虚构网页。

## 自检规则
1. 输出必须包含全部8个章节：学习目标、核心问题、个人概念理解、核心机制与组成、实际应用场景、易混淆概念与使用边界、自测问题、可核查参考资料
2. 参考链接必须真实可正常访问，禁止虚构链接
3. 不写死固定概念，支持任意 concept_name 输入
4. HTML标签完整规范，结构完整
5. 概念解释不能直接大段照搬AI原始输出，需要做整理改写
