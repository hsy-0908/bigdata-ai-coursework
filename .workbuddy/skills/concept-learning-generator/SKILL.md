# 概念学习资料生成Skill
## 适用场景
对任意人工智能、大模型相关概念生成完整学习资料，不限于Agent、上下文等指定主题，支持任意新概念输入。

## 输入
参数：`concept_name`，字符串类型，接收要讲解的技术概念名称。

## 执行步骤
1. 获取传入的`concept_name`概念名称
2. 撰写个人理解：个人对该概念通俗解释
3. 梳理核心原理与组成结构
4. 列举现实业务落地应用场景
5. 区分易混淆概念，说明使用局限与边界
6. 搜集真实可访问的公开参考资料链接，禁止编造链接
7. 输出完整HTML格式文件

## HTML输出强制5大章节
1. ### 个人对概念的理解
2. ### 核心机制与组成
3. ### 实际应用场景
4. ### 易混淆概念与使用边界
5. ### 可核查参考资料

> 文件命名规则：概念转小写，横杠分隔，如 Agent → agent.html

## 资料规范
参考链接必须是互联网真实公开地址，禁止虚构网页。

## 自检规则
1. 输出必须包含全部5个章节
2. 链接可以正常访问
3. 不写死固定概念，支持任意concept_name输入
4. HTML标签完整规范
